# CHANGELOG

- 1.18.6 強スイカを外したときは弱チャンス目の形で取りこぼす（スイカの上段を残さない形）。サイドランプの赤は、チェリー当選の予告か、ボーナス確定中のハズレ（矛盾）のときだけ。弱スイカ・弱チャンス目では赤を出さない。ペカの先光り・ペカ予告は金に変更
- 1.18.5 スイカ系の出目を仕様どおりに。弱スイカ＝左上→右下の斜め（右上→左下は揃わない）、強スイカ＝上段横。どちらも第1リール上段にスイカが来たときだけ。弱チャンス目＝左上・中央・第3リール中段がスイカでテンパイし揃わない。第1リール上段のスイカは、スイカ系か弱チャンス目の確定のときだけ出る
- 1.18.4 CHANCE の文字を予告（リール停止前）から出さないようにした。青の予告カットインは REPLAY と表示。CHANCE の文字はスイカ・チェリー・チャンス目の結果がリール停止後に出たときだけ
- 1.18.3 レバー操作の文字（タップ: レバーON）を削除。データ見出し（G数・BIG・AT・合算）は数字の左に配置して高さを詰めた。押し順ナビは液晶の上に重ねて専用の帯を撤去。詰めた分は演出液晶を拡大（206px）しリールを下げた
- 1.18.2 サンド目のとき「サンド目をそろえろ！！！」を大きく表示してあおる
- 1.18.1 AT中のベルは揃いやすいが、ナビが出ないことがあり（60%でナビ）、ナビなしのときはハズレ目になることもある（30%）。押し順ナビの今押す数字を大きく。差枚数と確率は非表示にして演出液晶を拡大。リールが液晶に被らないように配置。7とバーは1マスいっぱい（縦は潰す）、小役・レア役は小さく。図柄の1マスは全図柄同じ
- 1.18.0 サンド目を追加。第2リールにバー・チェリー・バーの並びを用意（停止位置の組み合わせにだけ現れる）。AT中にスイカ・チェリーが成立すると、次から3G以内にサンド目を出す。第2リールを目押しで揃えると、AT G数を 5・10・15・20・25・30・50 のどれかで上乗せ。外れは何も起きない
- 1.17.5 上部文字の色を期待度に（弱い予告=青 / 強い予告=赤）。ルーレット・コインは結果の役の色（ベル=黄 / スイカ=緑）で止まり、通常時の黄のうち約4%は緑で止まる矛盾演出（不可解な音＋赤く光る）。雨→虹は大きな当たりのときだけ虹
- 1.17.4 色のルールに反していた演出を修正（ステップ完走・矛盾の金/青カットイン、連続演出の青、ルーレット・コインの色、上部文字の青）。通常時のルーレット・コインは結果の色で止まる。矛盾の台詞は消して不可解な音だけにする
- 1.17.3 通常時の色の予告を追加（黄=ベル / 緑=スイカ / 赤=チェリー / 金=当たり / 虹=大きな当たり / 白=約束なし）。色が出た時は結果が必ずそれになる。矛盾演出は文字を出さず不可解な音だけにする
- 1.17.2 通常時の青（CHANCEカットイン）は必ずリプレイ。結果がリプレイのときだけ青の予告を出す
- 1.17.1 7図柄を大きく（横長に潰れてもよい）。LAST カウントダウンはレバー・STOP を押した時点で消える
- 1.17.0 STOPボタンを赤丸（待機）/青丸（押せる時）に。絵柄の行間を詰め、演出液晶を拡大、上部カウンターを圧縮し枠を両端まで広げた。チャンス目は対象の絵柄だけ光らせる。上部ペカり君文字がチャンス（青）・激熱（赤）で一瞬色変わり。文字色に虹・赤虹を追加（UP!の最上位で赤虹）。AT中は筐体枠と背景が橙、BIG中は赤に変わり脈動する（画面の空気感で今の状態が分かる）
- 1.16.1 構成の整理。単一の app.js を役割ごとのファイル（JS/data・core・game・ui）に分割し、CSS/・assets/・md/ を追加。確率・枚数などの数字は JS/data/config.js に集約。動作・見た目は変更なし（起動時の画面を含めてバイト一致、40回転の表示・保存データが一致）
- 1.16.0 以前: 履歴なし（この版以前は手元に記録が無い）
