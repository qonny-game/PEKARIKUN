# 演出の例外ルール一覧

「こういう時は出さない」「重なったら順番」「○ゲームで消える」など、通常の演出に対する例外を、現在のコード（v1.38.0）から拾ってまとめたもの。
停止順・取りこぼし・恩恵は `JS/data/rules.js` に集約済み。ここは演出側のルール。

## 1. 「枚 GET」を出さない場面（PAYOUTの数字だけ出す）
| 場面 | 場所 |
|---|---|
| PEKA CHANCE で確定表示（白7・スイカ・白7）が出たあと | bell.js showGet / reel-spin.js |
| 鼓動演出中（isSuspense） | bell.js showGet |
| 演出中（FX.busy > 0） | bell.js showGet |
| 液晶演出の表示中（CZ当選・割れ演出・レバー叩け・BIG/REG突入・ゾーン突入・サンド目揃い・7示唆・LEVEL UP） | bell.js showGet |
| ボーナス最終G（JUDGEMENT） | bonus.js |
| ボーナス中のチェリー/スイカで取りこぼしたゲーム（枚数は0） | bonus.js |
| LEVEL UP の表示中（背面の枚GETを消す） | lcd.js |
| 第3停止後に図柄の示唆が出るとき（消してから出す） | lcd.js |
| PUSH演出（G数上乗せ）が出るとき（背面の枚GETを消す） | at.js |
| 次の回転を始めるとき（前の表示を消す） | bell.js hideGet |
| RUSH中のリザルト（枚数は出さずG数の上乗せだけ） | at-result.js |

## 2. LEVEL UP（オーラ昇格）を出さない場面
- PEKA CHANCE で確定表示が出たあと（表示・効果音・レア役の告知とも）。
- デバッグ再生中。
- ゾーン（PEKA PEKA MOUNTAIN）中は出ない。

## 3. 重なる演出は順番にする
| ルール | 場所 |
|---|---|
| バナーは、前の演出（カットイン・ステップ・会話・暗転・別のバナー）が消えてから出す（待ち行列） | fx.js |
| 演出が表示中の間は、リールを回さない（カットイン・ステップ・会話・暗転・バナー・フラッシュ・矛盾演出） | fx.js startReels |
| 演出中（FX.busy > 0）はレバーを受け付けない | fx.js handleSpin |
| ウェイト: 前のレバーから約4.1秒（標準）空ける。足りなければ残り時間だけ待つ | fx.js |
| JUDGEMENT直前は演出を1つずつ順番に（0秒・1.2秒・2.3秒・3.5秒）。この間レバー・リールは動かない | bonus.js judgeIntro |
| 消灯で確定した上乗せは、回転が止まり、他のPUSH演出が終わってから表示 | flow.js awardPanelUp |
| 上乗せバトルは、サンド目・PUSH表示などが終わってから順番に始める | atpoint.js |
| ゾーン突入のカウントダウンは、開始演出（どどーん）が終わってから | fx.js |
| オートは、演出が終わってから次の操作をする | auto.js |
| 新しい回転の前に、直前の液晶演出（図柄・ハズレ・文字・キャラ）をすべて消す | flow.js / lcd.js clearAll |

## 4. 液晶の予告・示唆を出さない場面
- GOGO!ランプが光ったあと（通常時の予告・示唆・液晶のGOGO演出とも）。
- 確定のサイン（白7・スイカ・白7 / サンド目 / 色違いの7）が1回出たあとは、ボーナス図柄を揃えるまで演出（予告・前兆・矛盾の2択など）を出さない。サインは1回だけ。
- PUSHが出るゲームは、押す前に図柄や示唆を出さない（押したときに見せる）。
- PUSH中は、押すまで図柄を出さない。
- 雷の予告は、CHANCE ZONE突入かボーナスのゲームでしか出ない。
- 飛来物は予告のときだけ（背景として勝手には出さない）。
- CHANCE ZONE中に当選が決まったら、前兆（連続演出）は省略して当選画面へ。
- 内部状態（チェリー後の当選しやすい期間など）は通常は表示しない。
- 先ばれ（サイドランプの虹色）は、本当に確定しているときだけ出る（ガセなし）。押すのが遅れると消える（約9秒）。

## 5. 押し順ナビ
- 通常のゲームは押し順ナビなし（残っている表示は消す）。
- チェリー・スイカ（AT中・通常時）に押し順ナビは無い。
- サンド目に押し順ナビは出さない。
- ボーナス中のベル: 黄ナビ。30%は「1だけナビ」（最初の1つだけ表示）。押し順を間違えるとベルこぼし（1枚）でゲーム数は消化されない。
- ボーナス中のチェリー・スイカ: 数字なしで「!!!」の文字だけ。取りこぼしは枚数のみ（恩恵はもらえる）。
- AT中のベル: 85%でナビあり。ナビなしのときはハズレ目になることもある（10%）。
- SUPERの15枚役: ナビの1（7の画像）は7の位置（ランダム）。

## 6. ロゴ・表示が消える条件
| 表示 | 消える条件 |
|---|---|
| 中央液晶のRUSHロゴ | 突入から2ゲーム |
| 中央液晶のMOUNTAINロゴ・右パネルのMOUNTAINロゴ | 突入から2ゲーム |
| 右パネルのPEKA RUSHランプ | RUSH中は点灯し続ける（PEKA CHANCE中は光らない） |
| BIG BONUS / REG BONUS のタイトル | 約3.2秒で消える（ゲーム数ではなく時間） |
| 液晶のセリフ・文字 | 表示時間が過ぎると消える（約1.8秒が標準）。次の演出が来ると上書き |
| LASTカウントダウン | レバーON・STOPを押すと消える。ボーナスの残り3G以内に表示 |
| 取りこぼし表示 | 数秒で消える |

## 7. 下パネル（PEKARI-KUN の看板）の消灯
- 回転中に消えたら確定（CHANCE ZONE=当選確定 / PEKA CHANCE=AT当選確定 / RUSH中=100G以上の上乗せ確定）。確定でないゲームでは絶対に消えない。
- 消灯率: CHANCE ZONEの当選ゲーム 20% / RUSH中 0.8% / PEKA CHANCE中のAT当選ゲーム 4%（1回のボーナスで最大1回）。
- 裏モードON中は、当選フラグが入った瞬間に必ず消える（AT・ボーナス中を除く）。
- 戻る条件: CHANCE ZONE=BONUS確定画面が出る・CZの最終ゲームが終わる・ボーナス開始 / PEKA CHANCE=最終ゲーム（JUDGEMENT）が終わる・RUSH突入 / RUSH=上乗せ演出が済む・AT終了。

## 8. その他の例外
- デバッグ再生中は、G数・回数・差枚数を変えず、演出の一部（トロフィー・称号・パネル消灯）も出さない。
- AT結果: ボーナスだけで終わった場合（RUSHに入らなかった）は、RUSH扱いにせず、右パネルのRUSHランプも点けない。
- 設定示唆（OVER）は条件を満たしても稀にしか出ない。通常の枚数は必ず出る。
- 画面を隠す・閉じると、音をすぐ止める。隠している間は音を鳴らさない。
- オート中、設定画面などのモーダルが開いている間はオートが止まらず待つ。
- 視差・動きを減らす設定の端末では、背景のゆっくり動く演出と、強烈なフラッシュの点滅を止める（1回だけ）。

## 9. CZ当選ゲームのフリーズ演出（1.38.2）
- 条件: CHANCE ZONEの当選ゲームで、下パネル消灯・確定のサインが出ていないとき（約5%）。白7スイカ白7も同時には出さない。
- CZ失敗の直後のゲームでも、約5%で同じ演出になる（失敗の表示のあと、実は当選している）。
- 流れ: 第2リールが止まらない → 押してから3秒後に液晶が消える → 2秒間真っ暗 → BONUS確定。

## 確認したいこと
- 「BONUSタイトル表示は○回で消える」のような**ゲーム数で消えるルール**は、今は無い（時間で消える）。必要なら ○G で消す形にできる。
